# Fraerish bot

Telegram-бот: погода с прогнозом на ближайшие часы, курсы НБРБ и криптовалют, поиск картинок, исправление раскладки и ежедневная сводка, которую каждый чат и группа настраивают под себя.

## Команды

| Команда | Что делает |
|---|---|
| `/start` | справка и меню сводки; в личке сразу включает сводку |
| `/s` (`/settings`) | меню сводки: время, города, валюты, что присылать |
| `/stop` | выключить сводку |
| `/w Минск, Брест` | погода сейчас и на ближайшие 12 ч (OpenWeather); без параметров — города из настроек чата |
| `/e USD, EUR, BTC` (`/exchange`) | курс НБРБ, а если его там нет — криптовалюта с Binance (в $ и BYN); без параметров — валюты из настроек чата |
| `/e 100 usd eur`, `/e 0.5 btc`, `/e 50$` | пересчёт суммы через курсы НБРБ/Binance; без целевой валюты — в BYN (из BYN — в USD и EUR) |
| `/pick бар, кино, дома` | случайный выбор (варианты через запятую или «или») |
| `/poll Куда идём? Бар, Кино, Дома` | неанонимный опрос Telegram (2–12 вариантов) |
| `/top`, `/top 30` | кто больше всех писал в группе за 7 (или N) дней |
| `/g котики` | картинки через SearXNG, бот скачивает и загружает их сам |
| `/c ghbdtn` | перевод текста, набранного в латинской раскладке; `/c` ответом на сообщение переводит его текст; работает и при редактировании сообщения |

Списки городов и валют пишутся через запятую, регистр не важен; валюты можно разделять и пробелом. Список команд бот сам публикует в меню Telegram при старте. В группах команды выбираются из меню (Telegram подставит `@имя_бота`), если бот не админ группы.

## Ежедневная сводка

- В личке включается `/start`, в группе — кнопкой «Включить сводку» в приветствии, которое бот присылает, когда его добавили.
- Время и разделы сводки меняются кнопками. После кнопки «Города» или «Валюты» бот 5 минут ждёт следующее сообщение того, кто нажал, со списком через запятую (до 5 городов, до 5 валют); ответ на сообщение бота тоже работает. В группе бот видит обычные сообщения, только если он админ или у него отключён режим приватности (@BotFather → `/setprivacy` → Disable, затем добавить бота в группу заново); иначе — только ответом. Настройки в группе меняют только админы.
- Планировщик раз в минуту отправляет сводки чатам, у которых наступило время; после рестарта досылает сегодняшнюю, если её ещё не было. Если источник не ответил, повторяет до `bot.digest.retry-window` после назначенного времени, потом отправляет то, что есть.
- Если бота заблокировали или удалили из группы, сводка для этого чата выключается.

## Видео по ссылкам

Если в сообщении есть ссылка на TikTok, Instagram Reels или YouTube Shorts, бот без команды скачивает видео через [yt-dlp](https://github.com/yt-dlp/yt-dlp) и отвечает на это сообщение самим видео (mp4, H.264, до 720p, до 50 MB — лимит Telegram для файлов от бота). Одновременно качается не больше `bot.video.concurrency` роликов, остальные ждут; обработка других сообщений при этом не блокируется. yt-dlp (версия задаётся `YT_DLP_VERSION` в `Dockerfile`, файл проверяется по SHA-256 из релиза) и ffmpeg ставятся в образ; если сайты сломают скачивание, первым делом обновить версию yt-dlp.

## Угадайка «что в сторис»

- `/story` — неанонимный опрос «📸 Что в новой сторис?» с вариантами чата (по умолчанию: Пейзаж, Звёздное небо, Качалка, Селфи, Дорожка в качалке, Рилс) и кнопкой «🙋 Все проголосовали». Голоса бот получает через `poll_answer`.
- Когда проголосовали все, кто писал в группу за 30 дней (в личке — сразу), или нажата кнопка, опрос закрывается и появляется одно сообщение «🕵️ Что было на самом деле?» с кнопками. Каждый тайно нажимает свой вариант (видит только всплывающую подсказку), в сообщении — только «Ответили: N из M».
- Как только вариант набирает большинство проголосовавших — или ответили все и у варианта больше всего нажатий — то же сообщение превращается в итог «✅ В сторис: … 🎯 Угадали: …». Если ответили все, а большинства нет, — «🤥 Все жулики», игра закрывается без ответа и в рейтинг не идёт.
- `/story_top` — рейтинг «угадано N из M»; `/story_options Кот, Пёс` — свои варианты (2–12, админы); `/answer вариант` — ручное закрытие, только админы.

Таблицы: `story_games`, `story_votes`, `story_confirmations`, `story_options`.

## Статистика группы

Бот считает сообщения участников групп (только количество по дням и имя, текст не сохраняется) в таблице `message_stats`. `/top` показывает рейтинг, а по воскресеньям в 20:00 (`bot.stats.weekly-cron`) группы с включённой сводкой получают «📊 Итоги недели».

## Предупреждения о погоде

Раз в час (`bot.weather-alerts.cron`, с 07:00 до 22:00) бот смотрит прогноз по городам чатов с включённой сводкой и галочкой «Предупреждения». Если в ближайшие 3 часа ожидается дождь или снег с вероятностью от 50% или гроза, он пишет в чат, например «🌧️ Минск: с 15:00 возможен дождь (70%)». По каждому городу — не чаще раза в день; после рестарта счётчик дня начинается заново.

## Устройство

Одно Spring Boot-приложение. Каждая команда — реализация `CommandHandler`; `UpdateDispatcher` разбирает апдейты (команды, нажатия кнопок, ответы на сообщения бота, добавление в группу) и отдаёт их обработчикам.

```
telegram/   long polling, отправка ответов и меню, проверка админов, разбор апдейтов
command/    контракт команд, разбор команд и списков
settings/   /start, /settings, /stop, меню и кнопки настроек, права доступа
digest/     настройки чатов, сборка сводки и планировщик
weather/    /w, клиент OpenWeather, прогноз на ближайшие часы
exchange/   /exchange, клиенты НБРБ и Binance, форматирование курсов
image/      /g, SearXNG, скачивание и проверка картинок
layout/     /c
```

Данные — PostgreSQL 17 (контейнер `postgres` в compose, volume `pg-data`, наружу порт не открыт); схема создаётся и дополняется при старте из `schema.sql`.

Бэкап: `scripts/backup-db.sh` делает `pg_dump` в `/opt/fraerish-bot-backup/postgres` и хранит 14 дней; на сервере запускается cron-ом раз в сутки. Восстановление: `gunzip -c файл.sql.gz | docker compose exec -T postgres psql -U fraerish -d fraerish`.

## Сборка и тесты

Нужен JDK 21, Maven 3.9 и Docker (интеграционный тест поднимает Postgres через Testcontainers):

```
mvn verify
```

## Запуск

```
cp .env.example .env
docker compose up -d --build
docker compose logs -f bot
```

Переменные в `.env`:

| Переменная | Значение |
|---|---|
| `BOT_TOKEN` | токен от @BotFather |
| `BOT_NAME` | username бота без `@` |
| `OPEN_API_TOKEN` | ключ OpenWeather |
| `SEARXNG_SECRET` | случайная строка, например `openssl rand -hex 32` |
| `POSTGRES_PASSWORD` | пароль базы, например `openssl rand -hex 24` |

SearXNG наружу не публикуется: бот ходит к нему по внутренней сети compose. Входящие порты не нужны — бот работает через long polling.
